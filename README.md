# Maldives Atoll · 马尔代夫环礁

A standalone, interactive 3D Maldives atoll you can open in the browser.

**Live:** https://huagechen-lab.github.io/maldives-atoll/

## Controls

- Arrow keys move the camera (forward / back / strafe); works from the landing page too
- Drag to orbit, scroll / pinch to zoom
- Double-click to reset the camera
- Time presets: Day / Golden hour / Night
- Weather presets: Clear / Drift / Overcast / Rain / Storm
- Auto-orbit toggle
- Chinese / English UI: auto-detected from the browser, toggle in the top bar, remembered locally; `?lang=zh` / `?lang=en` override

Scene labels keep their original Chinese + English captions; only the landing UI switches.

## What it is

A single-file Three.js scene generated end-to-end by an LLM from one prompt:
procedural lagoon, reef islands, overwater villas, palms, a boat, and a
day/weather system. No backend, no tracking, no external assets beyond the
Three.js CDN.
